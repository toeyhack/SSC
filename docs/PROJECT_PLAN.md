# Project Plan

Build a CLI-first internal exposure assessment platform using authorized targets, separate scanner/evidence/rule/finding/scoring layers, and output adapters. Preserve completed Phase 0–4 work and the existing optional Web/API/frontend.

Complete and validate Phase 4B authorized HTTP/TLS/DNS/TCP executors first, then Phase 5 scoring, then CLI and REPORT. Dashboard-centric development is paused. SYGNOS must use the same normalized result model as REPORT; ingestion mapping and transport wait for its interface definition.

Refer to `AGENTS.md` for permanent engineering rules, `ROADMAP.md` for phase ordering, `ARCHITECTURE.md` for layer boundaries, `CLI.md` for operation and `IMPLEMENTATION_STATUS.md` for exact implementation/validation status.
